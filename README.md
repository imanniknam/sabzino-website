# سبزینو — چشیدن طعم‌های جهان

فروشگاه اینترنتی سبزینو؛ یک استارتاپ کارآفرینی اجتماعی با سه گروه اصلی محصولات سبزی‌محور، ادویه‌های بین‌المللی و نوشیدنی‌های طبیعی.

## امکانات

- فروشگاه و سبد خرید واکنش‌گرا
- ثبت‌نام، ورود و حساب مشتری
- ثبت سفارش و پرداخت آنلاین زرین‌پال
- پنل مدیریت مستقل در مسیر `/admin`
- مدیریت محصول، قیمت، موجودی و سفارش‌ها
- صفحات درباره ما، کارآفرینی اجتماعی، همکاری و تماس
- دیتابیس SQLite/D1 با Drizzle ORM
- رابط فارسی و راست‌به‌چپ با فونت Vazirmatn

## فناوری‌ها

- React 19 و Vinext
- TypeScript
- Cloudflare Workers و D1
- Drizzle ORM
- Caddy برای HTTPS و reverse proxy روی VPS

## اجرای محلی

پیش‌نیاز: Node.js نسخه `22.13.0` یا بالاتر.

```bash
npm install
npm run dev
```

سایت به‌صورت پیش‌فرض روی `http://localhost:3000` اجرا می‌شود.

## تنظیم درگاه پرداخت

فایل `.dev.vars` را کنار فایل تنظیمات Wrangler بسازید. برای اجرای VPS، این فایل در مسیر `deploy/.dev.vars` قرار می‌گیرد:

```env
ZARINPAL_MERCHANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
PUBLIC_SITE_URL=https://example.com
```

فایل‌های `.dev.vars` و `.env` در Git نادیده گرفته می‌شوند و نباید منتشر شوند. نمونه تنظیمات در فایل `.dev.vars.example` قرار دارد.

## دستورات مهم

```bash
npm run build
npm test
npm run db:generate
```

## ساختار پروژه

```text
app/             صفحات، کامپوننت‌ها و APIها
db/              اتصال و schema دیتابیس
drizzle/         migrationهای دیتابیس
lib/             منطق احراز هویت، محصولات و پرداخت
public/          تصاویر و فایل‌های عمومی
deploy/          تنظیمات و اسکریپت‌های استقرار VPS
deploy-offline/  ابزار نصب آفلاین
tests/           تست‌های پروژه
```

راهنمای استقرار در [DEPLOY-VPS-FA.md](./DEPLOY-VPS-FA.md) و راهنمای نصب بدون دانلود اینترنتی در [DEPLOY-OFFLINE-FA.md](./DEPLOY-OFFLINE-FA.md) قرار دارد.

## نکات امنیتی

- هیچ رمز عبور پیش‌فرضی برای مدیر وجود ندارد؛ حساب مدیر در نصب اولیه ساخته می‌شود.
- مرچنت‌کد، رمزها، کلیدهای SSH، دیتابیس محلی و فایل‌های build نباید commit شوند.
- پیش از انتشار، مقدارهای واقعی را فقط در متغیرهای محیطی سرور قرار دهید.
